# F17 — Product UI / UX Redesign — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Re-skin and re-structure the study app's vanilla frontend into a dark-first,
violet, premium educational application — shared injected shell, 6-item nav, 7 redesigned
pages — with zero backend/API contract changes except one MIME line.

**Architecture:** Approach A — rewrite `tokens.css` to the approved dark-first violet system;
extract the duplicated sidebar/header into a single `shell.js` that injects the chrome around
each page's own `<main id="main">` from one nav-config array (no SPA, no router, no build);
add `ui.js` render helpers and `i18n.js` (CA default / ES optional, `localStorage`-persisted).
Self-host Inter (`.woff2`) and an SVG icon sprite.

**Tech Stack:** HTML5 static files, vanilla CSS (custom properties), vanilla ES5-style JS
(`defer` except `i18n.js`/`shell.js` which run in `<head>`), Python stdlib
`ThreadingHTTPServer` (`web/server.py`), `pytest` (dev-only). No framework, no npm, no build.

**Spec:** [`docs/superpowers/specs/2026-09-10-f17-product-ui-design.md`](../specs/2026-09-10-f17-product-ui-design.md)
· visual language [`docs/F17_UI_DESIGN.md`](../../F17_UI_DESIGN.md)
· audit [`docs/F17_UI_AUDIT.md`](../../F17_UI_AUDIT.md)

## Global Constraints

- **Backend:** the ONLY backend edit in all of F17 is `".woff2": "font/woff2"` added to the
  `_MIME` dict in `web/server.py`. No other change to `web/server.py` or anything under `app/`.
- **API:** no contract changes, no new endpoints. Every rendered value comes from an existing
  API field (audit §5). No invented data — sections without data hide or show an honest empty state.
- **Frontend stays vanilla:** no framework, no build step, no npm, no new runtime dependency.
- **Preserved invariants:** CSRF double-submit (`csrf.js` untouched); 3px `:focus-visible`
  ring; `@media (prefers-reduced-motion: reduce)` global block in `base.css`; formula
  rendering (`.formula` family in `base.css`); "presentation layer only — no domain logic in
  the frontend"; academic content never translated.
- **Nav (single source, `shell.js`):** `Inici` (index.html) · `Temari` (temari.html) ·
  `Pràctica` (practice.html) · `Tutor IA` (tutor.html) · `Progrés` (progres.html) ·
  `Exàmens` (exams.html). Groups: ESTUDI {Temari, Pràctica}, APRENDRE {Tutor IA, Progrés},
  AVALUACIÓ {Exàmens}. No `documents.html` / `calendar.html` / `history.html` in nav.
- **Redirect stubs:** `study.html` → `temari.html`; `learning.html` → `progres.html`;
  `history.html` → `exams.html#historial` (via `<script>location.replace(...)</script>` +
  `<link rel="canonical">` + a `<noscript>` link).
- **Status badge thresholds (FROZEN — verbatim, spec §4.2 / DECISION_LOG D185):** applied only
  when `mastery.attempts > 0`; `score` = `mastery.score` (0–1 float); half-open intervals:
  - `attempts == 0` or `mastery == null` → `No iniciat`
  - `0 < score < 0.40` → `Reforçar`
  - `0.40 ≤ score < 0.75` → `En progrés`
  - `0.75 ≤ score < 0.95` → `Domini alt`
  - `score ≥ 0.95` → `Completat`
- **Dashboard "Domini":** mean of `mastery.score` over topics with `attempts > 0` (approved).
- **i18n:** CA default, ES optional; chrome strings only; academic/KB content never translated;
  preference persisted in `localStorage` key `sm-lang` (values `ca` | `es`); the `language`
  query/body param is already accepted by the backend (`ca` | `es`).
- **Tests:** never delete or weaken an existing test. Where a test encodes a structure the
  approved spec changes, reconcile it — preserving assertion intent and strength — and record
  the edit in the Test Reconciliation Ledger (Task 1). Full suite must return to the F17
  baseline: **889 passed, 1 skipped, 0 failed** (skip = `test_home_defaults_under_xdg_on_posix`).
- **Fonts self-hosted** (`web/static/fonts/InterVariable.woff2` + `OFL.txt`); icons from
  `web/static/icons.svg` sprite.
- **No automatic commits beyond each task's own commit; no merge, no tag, no release.**
- Work on branch `feature/f17-product-ui`. One focused commit per task. No unrelated refactors.
